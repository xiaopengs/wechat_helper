INSTALLATION
06 / 08
5 分钟上手

macOS 5 分钟
跑起来

环境准备 → 克隆 → 安装 → 启动 → 接 Agent，五步完成。⚠️ 仅 macOS，Win/Linux 未测试。

01
装依赖
# macOS 装 Bun / gh / Caddy
brew install bun gh caddy
xcode-select --install
02
克隆仓库
git clone https://github.com/
  superset-sh/superset
cd superset
03
安装依赖
# Bun 1.0+ 必装
bun install
04
启动桌面应用
# 弹出桌面应用
bun run dev
05
连接任意 CLI Agent
在应用内配 API Key
接 amp claude-code 任意 CLI 编码 Agent
💡
第一次启动会下载 Bun 引擎约 30 MB，耐心等 1-2 分钟。
macOS 用户 + 想多 AI 协作 → 值得装。
