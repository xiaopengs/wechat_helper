5 大特性
重塑编码工作流

并行工作区 + 智能体监控 + 持久终端 + 内置 Diff + 应用浏览器，把多 AI 协作做成 IDE 主形态。

01 · PARALLEL
并行工作区
10+ Agent 各占独立 Git Worktree，可对比、可合并优胜方案。
02 · MONITOR
智能体监控
侧边栏状态 + 完成提示音 + Dock 徽章 + ⌘I 富文本编辑器。
03 · TERMINAL
持久化终端
标签页 / 拆分 / 预设，Bun PTY 会话可重启恢复。
04 · DIFF
内置 Diff 查看器
IDE 内审查、评论、修改智能体代码，一键 commit + push。
05 · BROWSER
应用内浏览器
自动发现开发服务器端口，浏览器面板直接预览。
+ · BONUS
命令面板 + 远程
⌘K 命令面板 + 远程工作区（自定义命令唤醒离线主机）。
横向对比 + 合并优胜，多 AI 协作像 PR Review。
