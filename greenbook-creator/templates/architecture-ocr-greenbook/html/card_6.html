PER-FILE LOOP
逐文件并发子任务

01KEY POINTS · 关键点

并发评审

默认 concurrency = 8，PLAN + MAIN AGENT + 模型压缩三件套
  • 默认 concurrency = 8 并发
  • 可选 PLAN 阶段处理 ≥50 行大 diff（不开放工具）
  • MAIN AGENT 最多 30 轮取证，调用 task_done 才算完成
  • 模型压缩：60% 上下文异步触发，80% 同步触发
  • 预算超限时由程序继续分发文件
单文件独立评审，互不阻塞；模型压缩让长会话可控
