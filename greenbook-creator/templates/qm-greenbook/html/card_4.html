5 大特性
重塑协作 agent

per-scope 隔离、vendor-neutral、Slack+Web 同身份、admin 控制、skill packs — 把多人协作做成 agent 主形态。

01 · SCOPE
Per-scope 隔离
每人/每房间独立 memory · files · keychain · permissions · crons · web apps · sandbox。
02 · NEUTRAL
Vendor-neutral
不绑定 LLM 厂商，Pi / OpenCode / Codex / Claude Code 任选，部署不被锁定。
03 · SLACK+WEB
同身份双形态
同一身份同一配置在 Slack 和 Web 间无缝切换，协作跟人走。
04 · ADMIN
Admin 控制台
组织级配置 + 安全姿态（Strict / Auto / Dangerous）+ 模型白名单 + skill 审批。
05 · SKILL PACKS
Skill packs
从 git 仓库导入 skill 包，scope 内分享，admin 控制晋升到全组织。
+ · BACKGROUND
后台不间断
crons + watchers 在没人盯的时候跑：分拣 issue、定时 PR review、夜间报告。
multiplayer · 多沙箱 · 多 harness，公司级 agent 网。
