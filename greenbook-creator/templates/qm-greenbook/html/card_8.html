6 条坑

贡献规则、fork 风险、安全姿态、命令黑名单、skill 共享、漏洞披露 — 6 件装之前要知道的事。

⚠
贡献只接 .md/.txt：在 adrs/ 目录用文字描述需求，代码由 qm 团队实现，不接 PR 代码。
⚠
别用 GitHub fork 私有化：fork 共享对象网络，public 侧可按 SHA 拉到 fork 的 commit，企业慎用。要私有化走 git clone --bare。
⚠
默认 Auto 安全姿态：Strict 太严（每次工具调用都要人批），Dangerous 太松（无筛查），Auto 由 classifier 过滤外部数据。
⚠
命令黑名单绕不开：recursive delete / 危险 SQL 等硬禁令即使 Dangerous 姿态也保留，安全兜底不能关。
⚠
Skill 用 git 仓库导入：不是 GitHub fork 共享，admin 控制 skill 是否能晋升到全组织。
⚠
漏洞走 SECURITY.md 私人渠道：发公开 issue 可能被认定为漏洞披露，看清楚再发。
6 条坑 挨个看，省去 80% 后续翻车。
