5 分钟上手

5 步把 qm
部署到自家云

qm init 一行生成部署仓库，然后装、配、推、验 — 完全不需要 qm 源码 checkout。⚠️ 部署跑在你自己云账号，不是 qm 公司的服务器。

01
初始化部署仓库
# 生成 org 专属部署仓库
npm exec --yes \
--package=@yc-software/qm@latest \
-- qm init . --org my-co \
--target fly
02
装依赖
npm install
# 初始化会走完剩下的步骤：
# infra · sign-in · credentials · Slack · deploy
03
配凭证
# 编辑 .env：
SLACK_BOT_TOKEN=xoxb-...
SLACK_SIGNING_SECRET=...
POSTGRES_URL=postgres://...
OPENAI_API_KEY=sk-...
04
部署到云
# 推到 Fly / AWS（自己的云账号）
qm deploy
# qm 仓库本身不带部署 CI
05
验证 + 切 harness
登录 Web UI · Slack 测消息
qm init 生成 deploy/layers/<org>/ 目录，公司专属东西放这里。
