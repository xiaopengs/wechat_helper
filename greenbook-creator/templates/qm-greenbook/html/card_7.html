适用 vs 不适用

4 类场景用得上
3 类绕道走

qm 是公司级多人协作 agent harness，不是个人 coding agent。判断标准：是否需要让 agent 在公司内多人协作 + 数据私有 + 不锁定 LLM。

✓ 适用场景 · 4 类
✓5-50 人 创业公司，Slack 重度
✓需要 per-employee 隔离，跨部门不串台
✓数据敏感 → 部署在自家云账号
✓不想锁定 Anthropic / OpenAI，harness 可换
✗ 不适用场景 · 3 类
✗个人用户：直接用 Claude Code / Codex CLI
✗<3 人小团队：overhead 大，单租户够用
✗不想管基础设施：用 SaaS 产品更轻
你是 YC 系 / Slack 重度 / 数据敏感 → qm 值得装
multiplayer agent harness是分水岭，需要的人离不开。
