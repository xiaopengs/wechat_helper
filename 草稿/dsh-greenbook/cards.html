DeepSeek Harness What is it
01 · 项目速览
DeepSeek 的开源
智能体框架 dsh
DeepSeek Harness（dsh）是 DeepSeek AI 官方开源的 agent harness—— 一套「一切皆插件」的智能体运行框架，由 Cordis 插件框架驱动。 模型适配器、工具注册表、会话日志、甚至 agent 主循环本身都是插件， 没有特权核心，每个部件都可以从配置里被替换。
开发者预览阶段，正在快速迭代——未来会有破坏性变更。 README · DeepSeek AI

DeepSeek Harness Why it matters
02 · 核心特性
为什么说
「一切皆插件」？
01
没有特权核心
模型适配、工具注册、会话日志、agent 主循环——全部是可替换的插件。
02
Profile + Bundle 分层组合
web / headless 双模板开箱即用，配置行可被上层 patch 逐条覆盖。
03
扩展即挂载
在插件树旁挂一个插件就完成扩展；注册是效果，插件卸载时自动回滚。
04
类型化事件驱动
session 持久事件 + agent 实时事件 + 能力策略事件，三类扩展点各司其职。

DeepSeek Harness Architecture
03 · 架构原理
Cordis 驱动的
插件树
一个运行中的 dsh 是一棵由分层 bundle 组合而成的插件树： dsh-base 提供模型适配、工具、持久化、沙箱与审批策略； dsh-web-app 加上浏览器应用；dsh-headless 提供无服务端的一次性执行器。
会话日志是模型上下文的唯一来源——「模型可见 = 已入日志」是运行时强约束。 Architecture · Session log
  • 服务按 ctx.llm / ctx.tools / ctx.sessions 等键注册，按需注入，加载顺序由依赖声明决定
  • 能力接缝（seam）可整体换实现：换一个 fs / sandbox 提供方，Bash、PTY、LSP 一起切换
  • 看本机启动树：dsh --profile web --dump-config

DeepSeek Harness Quickstart
04 · 5 分钟上手
一行命令
跑起 Web UI
1
启动
npx @deepseek-ai/dsh web — 默认地址 http://127.0.0.1:3080
2
配模型
Settings → Models，填入 DeepSeek API Key，保存即可用，无需重启。
3
选工作区
Choose workspace 添加项目目录，会话编辑器随即可用。
4
派任务
「总结这个仓库」——它能读写文件、跑命令、委派子任务、维护计划。
从源码跑：pnpm install → pnpm run build → pnpm dsh web
