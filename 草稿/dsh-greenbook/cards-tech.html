DeepSeek Harness 01 · Architecture
01 · 整体架构
一条主干，六个包
一个轮次按同一条循环流经六个核心包：driver 认领排队提示词 → 在会话日志上开轮 → 组装 prompt + 工具 schema → LLM 流式响应 → 工具注册表分发调用 → 每个模型可见的事实追加回日志。
DRIVERagent-loop认领输入、驱动循环
→
LOGsession事件溯源的唯一真源
→
PROMPTsystem-prompt段落 + schema 组装
→
LLMllm seam流式取模型响应
→
TOOLStools注册表 + 受保护执行
一切皆插件
模型适配器、工具注册表、会话日志、甚至 agent 主循环本身都是插件——没有特权核心。
替换即配置
注册是效果，插件卸载自动回滚；换 provider 就换掉整个能力接缝。
扩展 dsh = 在插件树旁挂一个插件，其余全在配置层解决。 docs/architecture.md

DeepSeek Harness 02 · Execution Model
02 · 执行原理
Turn / Step 双层模型
step = 一次模型请求 + 它调用的工具。turn = 零或多个 step：在第一个输入被认领前开启，直到没有未偿债务才关闭。
持久事件
12
turn/step/user/assistant/tool 全链路入日志
Surface 类型
3
user/message · assistant/message · tool/result
三条核心不变量
  • 模型可见 = 已入日志：任何到达模型请求的输入，都必须能从会话日志重建，运行时强约束
  • 请求是日志的纯函数：prompt + schema + 历史全部从日志派生，可完整重放
  • 事件三域分工：session 事件存事实、agent 事件管在飞工作、capability 事件挂策略

DeepSeek Harness 03 · Loop Runtime
03 · Loop 是怎么跑的
一轮的完整时序
1
输入入队，driver 被唤醒
followup/steer 写入 inbox，agent/status → running
2
turn/start + 认领批次
认领全部 next-step 输入 + 一条 next-turn 消息
3
agent/pre-step 拦截
waterfall 可改写或拒绝；拒绝则本轮不花 step
4
step/start → 组装请求
user/message 入日志 → system-prompt/assemble → 从日志派生历史
5
agent/request → llm/stream
流式返回 StreamChunk，逐块记 assistant/chunk
6
工具调用批次
tool/call 入日志 → 受保护流水线执行 → tool/result 回写
7
step/end → 决定续跑
工具还欠请求或有 next-step 输入 → 下一 step；否则 turn-stopping
8
turn/end → idle
持久事件收尾，agent/status → idle，等待下一轮唤醒

DeepSeek Harness 04 · Tool Pipeline
04 · 工具如何被调用
一条受保护的流水线
模型发出 tool-call 后，调用依次穿过 7 段流水线，任何一段都可以拦截：
1tool/call 入日志执行前先落账 + UI pending
→
2pre-executehooks · 权限 · 沙箱
→
3monotonic guards只能拒绝，不可翻案
→
4approval一次性询问，缺席即拒
→
5execute body超时/重试/metrics 环绕
→
6post-execute接受 / 替换 / 加上下文
→
7tools/result冻结的权威结果
fs 写门禁
工具-fs 的写/改先过 fs/write-intent / fs/edit-intent，先读后写策略由此注入。
guard 单调性
guard 没有 allow 结果——监听器顺序无法把拒绝翻回允许，权限只会单向收紧。

DeepSeek Harness 07 · Recap
07 · 一句话总结
记住这四件事
  • 架构：六包主干 + 一切皆插件，无特权核心，改哪换哪
  • 执行：turn/step 双层，会话日志是唯一真源，请求是日志的纯函数
  • 工具：7 段受保护流水线，guard 单向收紧，fs 写有门禁
  • Loop：driver 认领 → pre-step → step → llm/stream → tool → step/end，循环可整体替换
上手：npx @deepseek-ai/dsh web → 127.0.0.1:3080，填 API Key 就能派任务。 github.com/deepseek-ai/deepseek-harness
